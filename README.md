# Dynamic treatment effects: high-dimensional doubly robust inference under model misspecification

This repository contains the code for the paper  
*Dynamic treatment effects: high-dimensional doubly robust inference under model misspecification*.

## Data

The file `bencost.sas7bdat` is obtained from the replication dataset of Schochet et al. (2019), available at  
https://doi.org/10.3886/E113269V1

The file `data.csv` is obtained from the replication dataset of Huber (2022), available at  
https://doi.org/10.7910/DVN/FS0KBA

## References

Huber, M. (2022). *Replication data for “Evaluating (weighted) dynamic treatment effects by double machine learning”*.  
https://doi.org/10.7910/DVN/FS0KBA

Schochet, P. Z., Burghardt, J., and McConnell, S. (2019). *Replication data for: Does Job Corps work? Impact findings from the National Job Corps Study*.  
https://doi.org/10.3886/E113269V1
